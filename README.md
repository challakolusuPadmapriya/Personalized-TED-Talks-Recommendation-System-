# Personalized TED Talks Recommendation System

## 1. Project Overview
The Personalized TED Talks Recommendation System is an AI-powered application that recommends TED Talks based on users' interests, preferences, and viewing history.

It helps users discover relevant and interesting TED Talks using machine learning and recommendation techniques.

## 2. Objectives
- Recommend TED Talks based on user interests.
- Provide personalized recommendations.
- Improve the TED Talk discovery experience.
- Use machine learning to identify similar talks.
- Build an interactive user-friendly dashboard.

Clone the repository:

```bash

```

Install dependencies:

```bash
pip install -r requirements.txt
```

```bash

```
